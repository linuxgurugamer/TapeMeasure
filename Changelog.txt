TapeMeasure Changelog
=====================

0.10.19
-------
* When Remember unfinished points is enabled and an incomplete measurement has at least point A, the main button now reads "Continue Measuring" while measurement mode is stopped.

0.10.18
-------
* Reduced the Keyboard bindings list height by one and a half standard button heights to leave additional space below the list.

0.10.17
-------
* Removed the Snapping, Automatic Vessel Dimensions, and Measurement List pane-expansion controls from Settings > Interface.
* Added headings to the Snapping, Interface, Display, and Keyboard Settings tabs.
* Added spacing below the alternate KSP skin option.
* Expanded the Keyboard bindings list box to use the available Settings-window height.

0.10.16
-------
* Added a persistent option controlling whether an unfinished measurement is resumed when Start Measuring is clicked again.
* When the option is disabled, restarting measurement mode discards the unfinished points and starts a fresh measurement of the same type.
* The option defaults on to preserve the existing resume behavior.

0.10.15
-------
* Added a live distance readout while positioning point B of a distance measurement.
* The preview value is drawn beside the live measurement line using the current units and precision settings.

0.10.14
-------
* Fixed vessel X/Y/Z axis constraints so the live preview endpoint follows the mouse along the constrained axis.
* Constraint placement now uses the closest point between the mouse camera ray and the vessel-axis line, with the previous projection retained only as a near-parallel fallback.

0.10.13
-------
* Fixed MeasurementSortMode compile error by using the existing Creation enum member for the Created sort button.

0.10.13
-------
* Keyboard shortcuts are now shown in a dedicated scrollable list box below the Settings tabs.
* Hidden-window measurement reminder now flashes at a one-second interval.
* Widened the Created sort control in the Measurement List.
* Added a snapping-active measurement cursor derived from the normal cursor.
* X/Y/Z axis constraints are shown directly on the measurement cursor while held.

0.10.11
-------
* Escape is now a hard-wired exit from measurement/endpoint-edit mode, in addition to the configurable Cancel shortcut.
* Starting measurement mode now closes the Settings window if it is open.
* CAD-style dimension end ticks were enlarged, thickened, oriented to the camera, and offset slightly toward the camera so they remain visible above the vessel surface and endpoint markers.
* Vessel X/Y/Z axis constraints remain configurable on the Settings > Keyboard tab; defaults are Alt+X, Alt+Y, and Alt+Z.

0.10.10
-------
* Added a "Marker Appearance" heading and spacing at the top of the Markers settings tab.

0.10.9
------
* Shortened Settings tab labels to Snapping, Interface, Display, Markers, and Keyboard.
* Reduced the Settings window scroll area height so the Settings window is more compact while retaining scrolling within each tab.

0.10.8
-------
* Settings window reorganized into Snapping, Interface, Display, Marker appearance, and Keyboard shortcuts tabs.
* Settings window open/closed state is no longer persisted; it always starts closed when entering the editor.
* Snapping layout now forces the containing window height to be recalculated when the snap-target column count changes.

0.10.7
	Updated snap toggles on main window to change layout based on window width
	Made the hidden-window "Press Esc to end measuring" reminder blink on/off every 2 seconds

0.10.6
-------
* Measurement List now measures the rendered width of the current Type, Lock, Value, X, Y, and Z data before drawing the table.
* Automatically widens the main Tape Measure window when necessary so list data remains on one line without wrapping or clipping.
* Current units and precision are included in the width calculation, so larger mm values or higher precision automatically receive enough room.
* The Name column remains fixed at its existing width; extra user-resized width is still distributed across Value and X/Y/Z.

0.10.5
-------
* Keep the Measurement List Name column at a fixed width when the main window is widened.
* Distribute additional horizontal space across the Value and X/Y/Z data columns instead.

0.10.4
-------
* Measurement List now expands horizontally with the resized main window.
* The Name column absorbs the additional width while the remaining columns stay aligned.
* The existing 12-character list-name display limit is unchanged.

0.10.3
-------
* Show a persistent "Press Esc to end measuring" message when the main window is hidden during measurement mode.
* Limit measurement names shown in the Measurement List to 12 characters; full names remain editable in Selected Measurement.
* Make the main Tape Measure window horizontally resizable with a right-edge drag bar.
* Remember the resized main-window width between sessions.

0.10.2
------
- Added display precision control with Automatic, 1, 2, 3, or 4 decimal places.
- Precision setting applies to measurement values, editor/world labels, guide labels, clipboard text, and formatted CSV values.
- Raw stored measurement values and raw numeric CSV columns remain unchanged.
- Added optional free-text Notes for each measurement in the Selected Measurement pane.
- Notes are included in measurement persistence, Undo/Redo, symmetry-generated copies, and CSV exports.
- Measurement-list filtering now searches Notes in addition to name, group, and type.
- Note editing is coalesced into a single Undo operation rather than one entry per keystroke.
- Measurement persistence database updated to version 7 for Notes support.

0.10.1
------
- Added optional X/Y/Z value labels directly on selected measurement projection guides.
- Guide labels use the current distance units and matching X/Y/Z guide colors.
- Guide labels respect the existing measurement-dimension-value display preference.
- Added direct selection by clicking visible measurement lines, endpoint markers, or world labels in the editor.
- Editor-graphics selection is disabled while placing measurements or dragging endpoints so it does not interfere with those workflows.

0.10.0
------
- Added persistent per-measurement colors with list swatches and palette selection.
- Added measurement groups/categories with collapsible group headings and group visibility toggles.
- Added measurement-list filtering and sorting by creation order, name, type, or value.
- Added configurable vessel X/Y/Z axis constraints while placing points.
- Added CAD-style distance end ticks.
- Added bidirectional hover highlighting between measurement rows and editor graphics.
- Added customizable keyboard shortcuts with key-capture and reset-to-default controls.
- Measurement persistence database updated to version 6 for group/color metadata.
- Corrected TapeMeasure.version KSP compatibility metadata to KSP 1.12.x.

0.9.2
-----
- Added per-measurement visibility controls and persistence.
- Added snapping to existing TapeMeasure measurement endpoints.
- Added angle-arc visualization.
- Added optional vessel bounding-box visualization.
- Added Redo with Ctrl+Y / Ctrl+Shift+Z and a Redo button.

0.9.1
-----
- Added an option to hide the main window while measurement mode is active.
- Restored the main window automatically when measurement mode ends.
- Renumbered the release series to 0.9.1.

0.9.0
-----
- Initial 0.9.x release baseline.
